## 0. 一页速读

| 项 | 结论 |
| --- | --- |
| 备份什么 | MEM-L3 获授权数据：用户偏好、开发习惯、日程习惯、**重要标记**；不含 L1 原始对话、L2 摘要、普通操作历史、敏感文件内容 |

| 云端预留 | **以账号为单元、1 GiB/账号、按 5000 账号规划（≈5 TiB）** ※非 PRD 原文，产品后续补充 |

### 1.3 明确划在记忆模块之外的

- **TEE / API 密钥安全存储**（PRD1 `:561 AI-21`）：云端大模型 API 密钥经 K3 TEE 存储，属端云路由/安全；**记忆不需要云端大模型 API 密钥**，也不因开启云备份就上传对话给模型。
- **敏感数据加密的密钥生成 / 轮换 / 导出**（PRD2 `:809`/`:818`/`:820`）：归安全模块，记忆模块不参与。
- **敏感操作确认级别**（PRD2 `:334` 之一）：归安全模块。

> 记忆模块与「密钥」的关系只有一条：**Capsule 数据密钥**（真正加密记忆的 AES-256-GCM 密钥），由记忆模块管理，属端侧。三层密钥的区别见 §3.4。

## 3. 需求 → 架构落点

### 3.1 四层记忆与云备份位置

- L1 工作记忆、L2 短期记忆（摘要 / 操作历史）：**只留本地**，永不进 Capsule。
- **L3 长期记忆**：本地 SQLite 权威 + 可重建索引；获授权后进入备份范围。
- **L4 云端记忆（可选）**：云端只存 L3 的**加密 Capsule**；不是另一套在线权威库。

### 3.2 备份链路（端侧）

`backup.create` / `run_scheduled` → 五项门禁 → 按 `scopes` 筛选 L3 → manifest → gzip → AES-256-GCM → 上传云端密文对象 → 写本地 `backup_jobs` / `backup_catalog`。

**五项门禁**（全满足才可生成 Capsule）：有效 API-Key ＋ 开关开启 ＋ 范围授权 ＋ 密钥可用 ＋ 云端 Adapter 可用。

### 3.3 恢复链路

列举云端对象 → 拉取密文 Capsule → 校验 checksum / schema → 解密 → 生成恢复预览 → 用户确认（confirm token）→ Tombstone 优先合并为新本地 revision → 重建索引。

### 3.4 密钥三层（最容易混淆，务必区分）

| 层 | 是什么 | 谁持有 | 记忆模块是否需要 |
| --- | --- | --- | --- |
| 云端大模型 API 密钥 | 调用云端大模型的凭据（PRD1 `:561 AI-21`，TEE 未实现） | 端云路由/安全 | **不需要** |
| **云端访问凭据 API-Key** | 代表账号访问云端记忆文件服务（`Authorization: Bearer <key>`） | 用户配置 | 需要（唯一云端凭据） |
| **Capsule 数据密钥** | AES-256-GCM，真正加密记忆数据 | 端侧派生（由 API-Key 经 HKDF 派生 KEK 再包裹） | 需要（记忆模块管理） |

跨设备 / 刷机恢复靠第三层的「账号密钥包」：设备 A 用本机 API-Key 派生 KEK、把 Capsule 密钥包装后上传；设备 B 用**同账号另一把 API-Key** 派生同一把 KEK，取回后本地解出。云端只存不透明字节。

### 3.5 「重要标记」的落点（R2）

- **载体**：记录上的**保留普通标签 `important`**——不是 `slot:` 槽位（每条记录最多一个槽位，会与该记录自身字段槽位冲突）。
- **置位**：只由用户/Agent 的**显式动作**（SDK / CLI / MCP 入口）；**绝不从记录文本推断**；已是目标状态时为 no-op、不消耗 revision。
- **为什么单独成域**：标记与内容类别（`kind`）正交——一条 `fact`/`decision` 本来不匹配任何内容范围。若并入 `preferences` 会**静默漏备份**，因此单列 `important` 范围。
- **端云格式零变更**：标记随既有 `tags` 字段进入 Capsule（manifest 与 payload 都在密文内），云端不解析；是否上传仍由 `backup_scopes` 是否包含 `important` 决定。
- **升级策略**：只把「仍是出厂默认值」的范围列表扩充为含 `important`；用户自定义过的列表不动。

## 4. 需要云端提供的接口（权威契约见 `docs/CLOUD_BACKUP_API.md`）

`Authorization: Bearer <key>`；`base_url` 含网关前缀。只列必做项。

| # | 方法与路径 | 用途 | 关键要求 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | `POST {base_url}/v1/agent-memory/files` | 上传密文对象 | 校验请求体 SHA-256；按 `backup_id` 幂等；同 ID 不同内容返 409 不覆盖；单对象 ≥64 MiB；不解析请求体 | 待云端 |
| 2 | `GET {object_ref}` | 拉取密文对象 | 返回原始字节 `application/octet-stream`；限制响应体上限；404→端侧 `NotFound` | 待云端 |
| 3 | `DELETE {object_ref}` | 删除密文对象 | 幂等（**404 视为成功**）；只作用本账号命名空间 | 待云端 |
| 4 | `GET {base_url}/v1/agent-memory/files?agent_id=&device_id=&limit=&cursor=` | 列举 / 查询（**换机恢复关键**） | 先按 API-Key 账号过滤，再按 Agent/设备过滤；游标不透明、`limit` ≤200、默认 `created_at` 倒序；支持 `include_deleted=true` | 待云端 |
| 5 | `GET {base_url}/v1/agent-memory/files/{backup_id}/meta` | 恢复前看大小/摘要 | 与列举单条同结构，不含对象内容 | 建议 |
| 6 | `DELETE {base_url}/v1/agent-memory/files?agent_id=&device_id=&before=` | 命名空间批量删除 | 返回 `{"deleted":N,"failures":[…]}`；**`device_id` 过滤是必需能力**（端侧缺省只删本设备） | 建议 |
| 7 | `PUT/GET/DELETE {base_url}/v1/agent-memory/key-envelope` | 账号密钥包（**刷机恢复必需**） | `key_id` 为 32 位小写十六进制；`envelope_epoch` 单调不减；原样回显；不得解析 / 改写 `wrapped_key`；DELETE 404 视为成功 | 待云端 |
| 8 | `GET {base_url}/v1/agent-memory/usage` | 账号级已用空间与配额 | `used_bytes`/`quota_bytes` 必回；**与上传预算同一口径**；只读幂等、端侧不轮询；未实现回 `404/405/501`，**不要**用 `200 {"used_bytes":0}` 冒充 | 待云端 |
| 9 | `PUT {object_ref}?part=N` + `POST {object_ref}/complete` | >16 MiB 分块上传（纯优化） | `complete` 回执与上传接口一致；未实现返回 `404/405/501`，端侧自动回退单请求 | 可选 |

**错误码**：`429 QUOTA_EXCEEDED`（账号容量用尽）为**终态、不重试**（`retryable=false`、不带 `Retry-After`）；`429 RATE_LIMITED` 才退避重试（必须带 `Retry-After`）。错误体 `{status, code, trace_id, message, retryable, retry_after_ms}`。

**明确禁止**：账号容量不足时**不得自动淘汰既有对象**腾空间——云端只持有密文与元数据，静默丢弃一份 Capsule 等于让用户无声失去一个可恢复点；只能明确拒绝，由用户显式清理。

## 6. 验收门禁

| 门禁 | 判定 | 依据 |
| --- | --- | --- |
| G-1 备份恢复成功率 **≥99%** | 模拟测试统计：上传 / 拉取 / 恢复成功比例 | PRD2 `:735`/`:856` |
| G-2 端到端加密（**P0**） | 云端对象为密文；无 Capsule 密钥时不可解密；密钥不落云端明文 | PRD2 `:655`/`:858` |
| G-3 摘要不上云 | 任意 Capsule 载荷 `session_summaries` 恒为空数组 | PRD2 `:643` + 产品决策 2026-09-07 |
| G-4 主题范围正确 | Capsule 只含授权范围命中的 L3 记录；`sensitive`/`secret`/`local_only` 一律排除 | R1 / R3 |
| G-5 **重要标记不漏备份** | 标记过的任意 `kind` 记录在授权 `important` 后进入 Capsule；未授权时不进入 | R2 |
| G-6 刷机 / 新设备一键还原 | 新设备仅凭同账号另一把 API-Key 完成列举 + 解密 + 恢复 | R7 / R8 |
| G-7 记忆检索 ≤100ms | 计时，P1 | PRD2 `:853` |
| G-8 容量可见可清理 | 账号用量可读（未知时显示「未知」而非 0）；满额时给出终态错误与清理入口 | R11 |
| G-9 删除不复活 | 清理前后旧 Capsule 恢复被 Tombstone / 删除水位拒绝 | R13 |
| G-10 门禁不旁路 | 五项门禁任一不满足即不得上传，错误码明确 | R5 |
